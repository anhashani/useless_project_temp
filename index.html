ℹ️ About ExcuseGen

The concept, ethics, and modern tech stack behind the solution.

Origin

TinkerHub Useless Projects

Born at TinkerHub Useless Projects, ExcuseGen playfully solves a relatable universal friction: the paralysis of staring at an unanswered message while running 15 minutes late.

Safety

Harmless by Design

We believe in harmless accountability. ExcuseGen strictly forbids fabricating serious illnesses, hospitalizations, deaths, accidents, or crimes, favoring genuine logistical hurdles and polite apologies.

Technology

Modern Django & AI

Built on Django 6.0 with the official OpenAI Python SDK (Responses API), featuring client-side localStorage privacy, CSRF token preservation, and vanilla modern CSS with zero bloated frameworks.
